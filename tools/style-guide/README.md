# Style-guide generator (house pattern)

`mercury-style-guide.html` is the Mercury Partners client style guide — a single self-contained
HTML file (fonts and logos embedded as base64 data URIs) published as a Claude artifact for
client-facing look-and-feel reference.

For a new client: duplicate this file, replace the token values in the `:root` block, swap the
embedded font/logo data URIs, and rewrite the content sections. Keep the section structure —
it's the house format: token swatches · type scale with live font rendering · signature-pattern
anatomy · component demos (buttons, forms, cards) · spacing table · imagery direction · voice &
copy rules · "Build Notes" audit of what NOT to carry forward from the old site · (optional)
reference-DNA analysis of the design's inspiration source.

Published Mercury edition (v1.1): https://claude.ai/code/artifact/edcc6fb7-adb8-45db-9370-0b8deb93a382
